# 홈코트 v1.0.0

2026-07-30 · 첫 배포

## 들어간 것

**오늘** — 준비물 칩 + 오늘의 순서(쿼터별 한 줄 요약). 열면 바로 시작할 수 있고 결정할 게 없다.
**운동 중** — 화면 테두리 전체가 타이머. 전환 3초 전에 테두리가 굵어지며 뜨거워진다. 소리를 꺼도 온전히 동작한다.
**플레이북** — 운동 42종 / 루틴 3종의 2층 라이브러리. 기본 운동은 숨김, 기본 루틴은 복제해서 편집. 길게 눌러 드래그로 순서 조정.
**원정** — 걷기·달리기 4주 프로그램. 시간 기반이라 GPS 없이 동작하고, GPS를 켜면 화면 꺼진 구간을 "직선으로 추정됨"으로 남긴다.
**기록** — 박스스코어(HOME/AWAY) · 야투율 · 달력 히트맵.
**설정** — 테마 · 언어(한/영) · 큰 글씨 · 소리 3종 · 조용 모드 · 운동 · 데이터 백업 · 안내 7종.
**덤벨 무게** — 첫 실행 3문항으로 시작점을 잡고, 세트 피드백으로 자동 보정. "쉬웠다" 2회 연속이면 올리자고 제안한다.

## 확정 수치

| 루틴 | 실제 분량 | 구성 |
|---|---|---|
| 타임아웃 | 6분 | 1Q + 쿨다운 · 6동작 |
| 기본 경기 | 16분 | 3Q + 쿨다운 · 11동작 |
| 풀 경기 | 35분 | 4Q + 컨디셔닝 + 쿨다운 · 20동작 |

분량은 하드코딩이 아니라 루틴에서 계산한다. 루틴을 고치면 표시도 따라간다.

## 알려진 한계

- **정해진 시간에 알림을 보낼 수 없다.** 웹 앱 공통의 한계라 기기 알람이나 단축어로 대신한다 (설정 > 안내에 방법 있음).
- **화면이 꺼지면 GPS 수신이 멈춘다.** 실기기로 확인했다 ([검증 결과](../../test/gps/결과-2026-07-30.md)). 러닝 기록의 주력을 시간 기반으로 잡은 이유.
- iOS는 진동을 지원하지 않는다. 그래서 신호가 전부 화면에 있다.
- 동작 그림이 아직 없다. 자세 큐 문장으로만 안내한다.

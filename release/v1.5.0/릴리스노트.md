# 홈코트 v1.5.0

2026-07-31

## 앱 아이콘이 드디어 홈코트 것이 됐습니다

**지금까지 배포된 아이콘은 템플릿 것이었습니다.** 프로젝트를 `_template-react-pwa`에서 복사해 시작했는데
`public/`의 아이콘을 한 번도 손대지 않아, 보라색 템플릿 로고가 그대로 올라가 있었습니다.
`icon-512.png`와 `icon-512-maskable.png`는 아예 같은 파일이라 maskable을 만든 적도 없었습니다.

이번에 **진입 화면 로고와 같은 그림으로** 넷을 전부 다시 만들었습니다.

- `icon-192.png` · `icon-512.png` · `icon-512-maskable.png` · `favicon.svg`
- maskable은 가장자리 10%를 비워 안드로이드 원형 크롭에서 잘리지 않습니다

로고 전체(가로로 넓은 하프코트)를 그대로 넣으면 40px에서 무너집니다.
코트 테두리의 둥근 사각형이 아이콘 자체의 둥근 사각형과 겹쳐 형태가 뭉갭니다.
그래서 **좌표는 하나도 바꾸지 않고 잘라낼 영역만 좁혀** 페인트존과 자유투 서클만 남겼습니다.
선 색은 진입 화면과 같은 흐린 흰색을 그대로 두고, 굵기만 올려 작은 크기를 버티게 했습니다.

## 기록 탭에서 러닝한 날이 안 보이던 것을 고쳤습니다

히트맵은 홈경기를 **채우기**로, 원정을 **테두리**로 나눠 보여줍니다.
그런데 그 테두리가 채우기와 같은 앰버였습니다.
**풀 경기를 한 날에 러닝까지 하면 테두리가 배경에 묻혀 사라졌습니다.** 다크·라이트 양쪽 모두에서요.

원정 테두리를 앰버 계열 밖의 색으로 바꿔 세 농도 전부에서 대비가 남게 했습니다.
범례와 날짜별 기록 시트의 점도 같이 맞췄습니다.

## 첫 실행 안내가 홈 화면 앱에서도 뜹니다

**홈 화면에 추가한 뒤 열면 안내가 한 번도 뜨지 않았습니다.**
"홈 화면에 추가하는 법"만 담고 있어서 이미 추가한 사람에게는 띄우지 않도록 짜여 있었기 때문입니다.

처음 쓰는 사람에게 필요한 것은 설치법만이 아니라 **이 앱이 무엇이고 어디에 무엇이 있는지**입니다.
그래서 안내를 다시 썼습니다.

- **공통**: 앱의 컨셉(층간소음 없는 실내 운동, 홈경기와 원정), 탭별 사용법 세 줄, 그리고 자세한 내용이 설정 탭의 앱 안내에 있다는 것
- **브라우저에서 볼 때만**: 홈 화면에 추가하는 방법 (아이폰 · 안드로이드 각 한 줄)

## 그 밖에

- **덤벨 무게를 물을 때 kg인지 알 수 있게** 했습니다. 라벨에 단위를 넣고 입력 칸 안에도 `kg`을 표시합니다
- **설정 화면이 전부 접힌 채로 열립니다.** 이전에는 '화면' 그룹만 펼쳐진 채 열려 그 그룹만 특별해 보였습니다
- 앱 정보(manifest)의 언어가 `en`으로 들어가 있던 것을 `ko`로 고쳤습니다
- 템플릿에서 딸려 온 `public/icons.svg`(다른 서비스의 아이콘 묶음)를 지웠습니다. 어디서도 쓰이지 않으면서 배포본에 실리고 있었습니다

## 아직 안 끝난 것 — 탭바 아래 여백

실기기에서 탭 라벨과 화면 아래 사이가 눈에 띄게 벌어지는 문제는 **이번 버전에서 고치지 못했습니다.**

브라우저에서 잰 값(안전 영역 = 0)으로는 탭바 아래쪽 끝이 화면 바닥과 정확히 일치했고
라벨 아래 여백은 26px이었습니다. 즉 레이아웃이 밀리는 문제는 없습니다.
아이폰에서는 여기에 안전 영역이 더해지는데, 그 값이 실제로 얼마인지 재지 않고 고치면 추측이 됩니다.

그래서 **측정 도구를 이 버전에 함께 실었습니다.**

```
https://respoflov.github.io/home-court/test/viewport/viewport-test.html
```

홈 화면에 추가한 뒤 열어야 홈 화면 앱과 같은 조건의 값이 나옵니다. 값을 받은 뒤 다음 버전에서 고칩니다.

# 홈코트 v1.1.0

2026-07-30

## 고친 것

**휴식 타이머가 멈춰 있던 버그** — 세트 사이 휴식 중에 "이 세트 어땠나요?" 시트가 뜨면 타이머가 같이 멈췄다. 시트에는 *"휴식이 끝나면 자동으로 다음 세트로 넘어가요"* 라고 적혀 있었으니 안내와 동작이 어긋나 있었다. 이제 시트가 떠 있어도 휴식 시계는 계속 가고, 휴식이 끝나면 시트가 알아서 닫힌다. (무게 올리기 제안만은 결정이 필요해 그대로 멈춘다.)

**바텀시트를 아래로 밀어 닫을 수 있다** — 손잡이를 잡고 내리면 시트가 손가락을 따라오고, 90px 이상 내리거나 빠르게 튕기면 닫힌다. 짧게 끌었다 놓으면 제자리로 돌아온다.
- 진입 애니메이션의 `animation-fill-mode: both`가 끝난 뒤에도 transform을 붙잡아 드래그가 안 먹던 문제를 `onAnimationEnd`로 해결했다.

## 더한 것

**버전이 자동으로 따라온다** — `package.json`의 `version`을 빌드 시 주입한다. 화면에 손으로 적지 않으므로 실제와 어긋날 수 없다.

**화면 켜두기 지원 여부를 표시한다** — 설정의 '운동 중 화면 켜두기' 부제에 이 기기에서 되는지 안 되는지를 적는다. 지원하지 않는 기기에서는 토글이 켜지지 않는다. 되는 척하지 않기 위해서다.

**무게가 딱 맞지 않을 때** — 설정 > 덤벨 무게에 항목을 넣었다.
- 고정 무게만 있어 중간이 없으면 가벼운 쪽 + 횟수 2~3회 추가
- 그래도 가벼우면 내리는 동작을 3초에 걸쳐
- 양손 동작을 한 손씩 나누면 그쪽 부하가 두 배
- 무거운 쪽밖에 없으면 6~8회로 줄이고 세트 추가, 자세 흔들리면 즉시 중단

**화면 켜두기 검증 도구** — `test/wakelock/wakelock-test.html`. 실기기에서 자동 잠금이 정말 막히는지 확인한다. GPS 도구와 함께 배포본에 실린다.

## 검증한 것

- **소리**: `OfflineAudioContext`로 실제 파형을 렌더해 확인. 틱(880Hz) 피크 0.176 / 전환(1046Hz) 0.178 / 버저(220Hz) 0.218, 길이도 설계값대로. 무음이 아니다.
  - 다만 **아이폰 무음 스위치를 켜두면 Web Audio 소리가 나지 않는다.** iOS의 알려진 동작이며 앱에서 우회할 수 없다.
- **세트 사이 휴식**: 설정값(기본 30초, 20/30/45/60 선택)대로 스텝이 삽입된다. 좌우 사이와 마지막 세트 뒤에는 넣지 않는다.
- **바텀시트 드래그**: 끄는 중 transform이 따라오고(35px 확인), 짧게 놓으면 되돌아오고, 길게/빠르게 내리면 닫히며 상태가 저장된다.

## 아직 실기기 확인이 필요한 것

- 아이폰에서 화면 켜두기가 정말 자동 잠금을 막는지 (`test/wakelock/`)
- 소리가 실제 스피커로 나오는지, 무음 스위치 영향
- 롱프레스 드래그가 터치에서 스크롤과 안 부딪히는지

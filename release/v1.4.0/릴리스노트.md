# 홈코트 v1.4.0

2026-07-31

## 기록 탭을 다시 짰습니다

**히트맵이 목차입니다.** 모든 기록을 아래에 주르륵 늘어놓던 것을 없앴습니다.

- **날짜를 누르면 그날 기록만** 시트로 열립니다. 칸에 날짜 숫자가 보이고, 기록이 있는 날만 눌립니다
- **히트맵 아래는 누적**입니다. 총 경기·총 시간, 루틴별 횟수, 많이 한 동작 5가지
- **월을 넘길 수 있습니다.** 헤더의 ‹ › 로 지난달 히트맵을 보고, 거기서도 날짜를 눌러 그날 기록을 엽니다
- **기록을 하나씩 지울 수 있습니다.** 시트의 휴지통을 누르면 확인 후 삭제됩니다

누적 통계를 내려면 어떤 운동을 했는지가 필요해서, 이제 세션마다 수행한 동작 목록을 함께 저장합니다.

## GPS가 무엇을 기록하는지 바로잡았습니다

**이전 버전의 "GPS로 거리·경로 기록"은 사실과 달랐습니다.** 실제로는 총 이동 거리만 계산하고 좌표를 하나도 저장하지 않았습니다. 경로라고 부를 것이 없었습니다.

이번 버전부터 **좌표를 실제로 저장하고 궤적을 그립니다.**

- 5m 넘게 움직였을 때만 좌표를 담아 용량을 줄입니다
- 기록에서 **지나온 궤적의 모양**을 볼 수 있습니다
- **배경 지도는 없습니다.** 궤적 모양만 그립니다. 문구도 "GPS로 거리와 궤적 남기기"로 고쳤습니다

지도 위에서 보려면 지도 API 연동이 따로 필요합니다. 아래 "지도 연동에 대하여"를 참고하세요.

## 지도 연동에 대하여

지금은 좌표를 정규화해 **SVG 궤적**으로 그립니다. 외부 의존이 없어 오프라인에서도 동작하고 앱 톤과도 맞습니다. 다만 "내가 어느 길로 갔는지"는 배경 지도가 있어야 알 수 있습니다.

실제 지도를 깔려면 선택지는 둘입니다.

| 방식 | 필요한 것 | 걸리는 점 |
|---|---|---|
| 카카오맵 JS SDK | 개발자 콘솔 앱 등록 + 배포 도메인 등록 | 외부 스크립트라 오프라인에서 지도만 안 뜸 |
| OpenStreetMap 타일 | 없음 | 타일 서버 사용 정책을 지켜야 하고, 역시 오프라인 불가 |

어느 쪽이든 **화면이 꺼지면 위치 수신이 멈추는 제약은 그대로**입니다. 궤적에 빈 구간이 생기는 것은 지도를 깔아도 해결되지 않습니다.

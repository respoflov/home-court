# 홈코트 (Home Court)

집에서 층간소음 없이 할 수 있는 운동만 모아, 정해진 순서대로 따라가게 해주는 개인용 PWA.
실내 운동은 **홈경기(HOME)**, 러닝은 **원정(AWAY)** 으로 기록됩니다.

> 조용히, 매일, 한 쿼터씩

- 배포: https://respoflov.github.io/home-court/
- 버전: 1.5.1 (설정 화면과 `package.json` 기준)

## 무엇이 다른가

- **점프 동작이 아예 없습니다.** 42개 운동 전부에 소음 등급(3단계)이 붙어 있고, 이른 아침·늦은 밤에는 발소리 나는 동작이 자동으로 빠집니다.
- **소리를 못 내도 온전히 동작합니다.** 새벽에 쓰는 앱이라 화면 테두리 전체가 타이머이자 전환 신호입니다. 소리는 켜고 끌 수 있는 거들기입니다.
- **무게를 사람이 계산하지 않습니다.** 세트마다 "쉬웠다/딱 좋았다/힘들었다"를 한 번 탭하면, 앱이 올릴 때를 알려줍니다.

## 개발

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # dist/
npm run lint
```

main에 푸시하면 GitHub Actions가 빌드해서 Pages에 배포합니다.

## 안전 안내

이 앱의 운동은 널리 통용되는 초급 동작을 "층간소음 없는 집"이라는 조건에 맞게 고른 것이며, 개인에게 맞춘 처방이 아닙니다. 특정 동작에서 날카로운 통증이나 저릿함이 오면 그 동작은 빼주세요.

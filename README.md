# 홈코트 (Home Court)

집에서 하는 층간소음 적은 홈트 루틴을 실행·기록하는 개인용 PWA. 실내 운동은 **홈경기**, 러닝은 **원정경기(AWAY)** 로 다룹니다.

- 상태: 기획·검증 단계
- 배포: https://respoflov.github.io/home-court/

## 현재 올라간 것

`gps-test.html` — 러닝 기능을 GPS 실시간 추적으로 만들 수 있는지 아이폰 실기기에서 검증하는 임시 테스트 페이지입니다. 앱 본체가 아니며, 검증이 끝나면 제거될 수 있습니다.

→ https://respoflov.github.io/home-court/gps-test.html

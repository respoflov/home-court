# 러닝 궤적 지도 연동 검증 — 2026-08-01

검증 대상: v1.5.1의 카카오맵 궤적 (`src/lib/kakao.ts` · `src/screens/Record.tsx`의 `Track`)
방식: 개발 서버에 표본 기록을 주입해 기록 탭에서 열어봤다. 시안은 `mockup/track-map-options-v2.html`.

## 무엇을 확인하려 했나

1. 07번("내 손안의 작은 부산")의 카카오 JavaScript 키가 08번에서도 동작하는가
2. 화면이 꺼져 있던 구간이 점선으로 구별되는가
3. **지도를 못 불러왔을 때 기록이 빈칸이 되지 않는가**

## 결과

### 1. 키 — 동작한다 (localhost 실측)

`http://localhost:5173`에서 지도가 정상적으로 떴다. 해운대 일대의 도로·건물·상호까지 나온다.

07번 `src/lib/config.ts`의 주석대로 이 키는 **오리진 단위**로 등록돼 있다
(`https://respoflov.github.io` · `http://localhost:5173`). 08번 배포 주소
`https://respoflov.github.io/home-court/`는 07번과 **오리진이 같으므로** 배포본에서도 동작할 것으로 본다.
다만 **배포 후 실제로 확인한 것은 아니다.** 배포되면 원정 기록을 하나 열어 확인할 것.

키를 07번과 나눠 쓰는 상태다. 카카오 콘솔에서 홈코트용 앱을 따로 만들면
`src/lib/config.ts` 한 줄만 바꾸면 되고, 오리진이 이미 같아 등록도 간단하다.

### 2. 점선 — 보인다. 단 처음에는 안 보였다

첫 표본은 끊긴 두 점 사이가 20m밖에 안 돼 점선이 보이지 않았다. **표본 데이터의 문제였다.**
실제로는 화면이 꺼진 동안에도 계속 달리므로 두 점이 멀리 떨어진다.
그 사이의 점들을 실제로 빼고 다시 확인하니, 붉은 점선이 건물을 가로지르며 뚜렷하게 나왔다.

재현용 표본 (브라우저 콘솔에서 `home-court.v1`에 넣는다)

```js
const legs=[[0,1,12],[1,0,9],[0,1,10],[-1,0,8],[0,-1,11],[-1,0,7]]
const full=[]; let lat=35.1630, lon=129.1600
for(const [dy,dx,n] of legs) for(let i=0;i<n;i++){
  lat+=dy*0.00018; lon+=dx*0.00022; full.push([+lat.toFixed(6), +lon.toFixed(6)]) }
// 화면이 꺼져 있던 동안의 점들을 실제로 뺀다
const track = full.slice(0,22).concat(full.slice(34))
// log.track = track, log.trackBreaks = [22]
```

### 3. 폴백 — 동작한다

SDK 주소를 `dapi.kakao.invalid`로 바꿔 `script.onerror`를 실제로 일으켰다.
배경 없는 SVG 궤적으로 되돌아가고, **점선 구간도 SVG에서 그대로 점선으로 유지**되며
"지도를 불러오지 못했습니다. 궤적 모양만 보여드려요."가 뜬다. 빈칸이 되지 않는다.

확인 후 주소는 되돌렸다.

### 4. 두 테마 모두 확인

다크·라이트 양쪽에서 열어봤다. 지도가 밝아 **다크 모드에서는 시트 안에서 혼자 밝게 뜬다.**
없앨 방법을 찾지 못했다. 카카오 JS SDK에 다크 타일이 있는지는 확인하지 못했고,
CSS 필터로 반전시키는 우회는 지도 표시를 임의로 바꾸는 것이라 약관 확인 없이 쓰지 않았다.
지금은 둥근 모서리와 헤어라인 보더로 감싸 카드 안에 들어앉게만 했다.

## 그래서 제품을 어떻게 정했나

- 지도는 **기록에서 그날 것을 펼칠 때만** 불러온다. 앱이 뜰 때 부르면 오프라인에서 앱 전체가 지도를 기다린다
- 끊긴 구간은 **붉은 점선 + 문장**으로 밝힌다. 거짓 거리를 사실처럼 보여주지 않는다는 기존 원칙을 따른다
- **지도가 안 뜨면 예전 SVG 궤적으로 되돌아간다.** 지도는 덤이고, 기록 자체가 사라져서는 안 된다
- 지도를 빌려 쓰므로 설정 > 오픈소스 라이선스에 Kakao Maps를 함께 밝힌다

## 반증 검토

- **"끊긴 자리를 시각(타임스탬프)으로 찾으면 되지 않나"** → 안 된다. 좌표는 5m 넘게 움직였을 때만 담기므로,
  신호 대기로 1분을 서 있어도 저장된 점 사이의 시간 간격이 벌어진다. 서 있던 것과 화면이 꺼진 것을
  구별할 수 없다. 그래서 **`visibilitychange`로 실제 원인을 직접 표시**하는 방식을 택했다
- **"5초 기준이 너무 짧지 않나"** → 알림을 확인하는 정도의 짧은 전환까지 끊겼다고 하면 궤적이 점선투성이가 된다.
  기존 `gapSeconds` 표시 기준(5초)과 맞췄다. 실기기에서 조정이 필요할 수 있다
- **"오래된 기록이 깨지지 않나"** → `trackBreaks`가 없으면 전부 이어진 것으로 그린다. v1.5.1 이전 기록은
  예전과 똑같이 한 획으로 나온다 (다만 지도 위에 그려진다)

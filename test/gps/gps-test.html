3. 테스트 순서

  1. 추적 시작을 누르고 위치 권한을 "허용"합니다. 팝업이 아예 안 뜨면 그 자체가 중요한 결과이니 그대로 기록됩니다.
  2. 집 앞을 3~5분 걸어 다닙니다. 화면을 켠 상태로 두고, 거리(METERS)가 실제 이동과 비슷하게 늘어나는지 봅니다.
  3. 전원 버튼을 눌러 화면을 끄고 2분 더 걷습니다. ← 이게 핵심 시험입니다.
  4. 화면을 다시 켜서 이 페이지로 돌아옵니다. 로그에 화면 꺼진 동안의 수신 기록이 남아 있는지, 최대 수신 공백이 몇 초인지 확인합니다.
  5. 추적을 정지하고 로그 복사를 눌러 채팅에 붙여넣어 주세요. 제가 해석해서 러닝 기능 방향을 결정하겠습니다.
로그는 자동 저장되어 앱을 닫았다 열어도 남습니다. 배터리를 꽤 쓰니 테스트 후엔 반드시 정지해 주세요.

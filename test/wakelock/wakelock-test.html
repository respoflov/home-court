3 · 테스트 순서

  1. 화면 켜두기 시작을 누릅니다. "잠금 유지"가 예가 되어야 합니다.
  2. 기기를 그대로 두고 2~3분 기다립니다. 손대지 마세요.
  3. 자동 잠금 시간(설정에서 확인, 보통 30초~2분)이 지나도 화면이 안 꺼지면 성공입니다.
  4. 일부러 전원 버튼을 눌러 끈 뒤 다시 켜면, 앱이 잠금을 다시 잡는지(재획득 횟수 증가) 봅니다.
  5. 로그 복사를 눌러 채팅에 붙여넣어 주세요.
전원 버튼으로 직접 끄는 것은 Wake Lock이 막지 못합니다. 막는 것은 가만히 뒀을 때의 자동 잠금뿐입니다.
